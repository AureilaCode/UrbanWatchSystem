==================================================
AI CLASSIFICATION
==================================================

The AI must analyze the uploaded complaint image and classify it into EXACTLY ONE of these categories:

1. Pothole
2. Garbage/Waste
3. Damaged Streetlight
4. Water Leakage
5. Other/Unknown

The AI response must contain:

- category
- confidence
- short explanation

Example:

{
  "category": "Pothole",
  "confidence": 0.91,
  "reason": "The image shows a visible depression and damage in the road surface."
}

The confidence is a model estimate and must NOT be described as a scientifically calibrated probability.

==================================================
ARCHITECTURE
==================================================

Use this flow:

User selects image
        ↓
Existing Cloudinary upload
        ↓
Cloudinary HTTPS image URL
        ↓
Frontend calls UrbanWatch backend
        ↓
POST /api/classify/image
        ↓
Backend authenticates Firebase user
        ↓
Backend validates the Cloudinary URL
        ↓
Backend sends image to the REAL vision model
        ↓
Vision model returns category + confidence + reason
        ↓
Backend validates the category
        ↓
Frontend displays AI result
        ↓
User can confirm/change category
        ↓
Final selected category is saved to Firestore issueType

The browser must NEVER contain:
- OpenAI API key
- Cloudinary API secret
- any other server-side secret.

==================================================
BACKEND
==================================================

Create:

artifacts/api-server/src/routes/classify.ts

Add:

POST /api/classify/image

The endpoint should:

1. Verify Firebase authentication.
2. Accept the Cloudinary HTTPS image URL.
3. Validate that the URL belongs to our configured Cloudinary hostname.
4. Reject arbitrary external URLs.
5. Reject missing/invalid image URLs.
6. Send the image to the real vision model.
7. Request structured JSON output.
8. Validate the returned category against EXACTLY:

Pothole
Garbage/Waste
Damaged Streetlight
Water Leakage
Other/Unknown

9. Validate confidence is a number between 0 and 1.
10. Return a clean response to the frontend.

Example:

{
  "category": "Pothole",
  "confidence": 0.91,
  "reason": "The image shows damage in the road surface."
}

If the model response is invalid:
- return an appropriate error
- DO NOT invent a category
- DO NOT invent a confidence score.
