Redesign ONLY the citizen/user-facing UI of my existing UrbanWatch application to make it feel like a unique, production-quality civic technology product rather than a generic dashboard template.

IMPORTANT: Before changing anything, inspect the existing application and understand the current component structure and routes.

## CORE RULE — DO NOT BREAK FUNCTIONALITY

This is a UI/UX redesign, NOT a backend rewrite.

DO NOT remove, replace, or break any existing functionality.

The following are already working and MUST remain working exactly as they do now:

* Firebase Authentication
* Firebase Firestore
* Cloudinary image uploads
* AI image classification using the existing backend
* AI category confirmation/change
* GPS / browser geolocation
* OpenStreetMap / Leaflet maps
* Complaint creation
* Complaint details
* Complaint status tracking
* Admin authentication and authorization
* Admin Dashboard
* Existing API routes
* Existing Firestore schema
* Existing security rules
* Existing environment variables/secrets
* Existing presentation/project files

Do NOT introduce Firebase Storage.

Do NOT change the database schema.

Do NOT replace the AI provider.

Do NOT modify the Admin Dashboard unless absolutely required for shared styling/components.

Do NOT create fake functionality or fake AI.

Use the existing real data and functionality.

# DESIGN DIRECTION

Redesign the citizen experience around the concept:

## "UrbanWatch — City Pulse"

The product should feel like a modern civic platform where a citizen can:

1. See what is happening around their neighbourhood
2. Report a civic problem quickly
3. Track what happens after reporting
4. See their contribution to the community

The design should communicate:

* Civic
* Modern
* Local
* Trustworthy
* Action-oriented
* Slightly futuristic
* Clean
* Human
* Mobile-first

It should NOT look like a generic banking dashboard, admin dashboard, CRM, or analytics template.

---

# VISUAL IDENTITY

Keep the existing UrbanWatch brand direction but refine it.

Primary visual language:

* Deep teal / dark blue-green
* Warm coral/orange for important actions
* Warm off-white background
* Soft mint/teal surfaces
* Small amounts of amber for warnings
* Green for resolved status
* Red/coral for urgent issues

Keep strong contrast and accessibility.

Use rounded corners, but avoid making every element look like an identical rounded rectangle.

Introduce visual hierarchy through:

* typography
* spacing
* large numbers
* image-based complaint cards
* subtle map/road patterns
* section labels
* icons
* status indicators

Avoid excessive gradients.

Avoid excessive glassmorphism.

Avoid excessive animations.

The result should look premium but still appropriate for a college project and civic application.
